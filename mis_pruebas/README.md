# Sus propias pruebas

Escriba aquí al menos tres pruebas que **antes eran imposibles**:

1. la vigencia calculada con un reloj fijo,
2. la cadena caída (la pasarela lanza `TimeoutError`),
3. una receta inválida rechazada en el borde.

Corren con `pytest mis_pruebas/`. La etapa 5 verifica que existan: pasar
las pruebas de otro es la mitad del trabajo; escribir la suya es la otra.
